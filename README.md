# Switchboard — Created by Vijay Dodiya

A multi-provider AI workspace for ChatGPT/OpenAI, Claude, Gemini and OpenRouter. Projects and complete conversations are saved in a server-side SQLite database, so changing AI providers or signing in from another device does not clear the project history.

## Included
- Single-owner password sign-in (`APP_PASSWORD`).
- Server-side projects and conversation history (SQLite).
- Continue the same project with a different AI provider/model.
- Project-linked file uploads up to 15 MB, with a visible upload control and attachment list/download links. TXT, Markdown, CSV, JSON, XML, HTML, logs and source files are extracted as text. PDF and DOCX text extraction uses the included `pypdf` and `python-docx` packages.
- Responsive desktop/mobile interface.
- Export and restore project/chat backups (restores create additional projects and do not overwrite existing ones).
- Creator credit: Vijay Dodiya.

## Run locally on Windows
1. Install Python 3.10 or newer.
2. Extract this folder.
3. Double-click `run.bat` (or run `python -m pip install -r requirements.txt`, then `python server.py`).
4. Open `http://127.0.0.1:8765`.
5. Set `APP_PASSWORD` and at least one provider API key in `.env`, then restart. Create `.env` from `.env.example` if it does not exist.

## Deploy for access from anywhere (Render)
1. Create a private GitHub repository and upload the project files. Do **not** upload `.env`, API keys, `data/`, or uploaded documents.
2. In Render, create a new Blueprint and connect that repository. Render reads `render.yaml`.
3. In the service's Environment settings, set a strong `APP_PASSWORD` and add the provider API key(s) you want to use. Keep `SECRET_KEY` generated by Render.
4. Deploy. Open the HTTPS address Render gives you on your phone, laptop or any other device and sign in with your owner password.
5. Keep the persistent disk mounted at `/var/data`. The SQLite database and uploaded files are stored there. Do not remove the disk or change `DATA_DIR` if you want to keep the same data.

**Hosting note:** persistent storage on Render requires a paid persistent disk/service plan. Do not deploy this SQLite configuration on an ephemeral/free instance if you need projects to survive restarts or redeployments. For a free hosting plan, connect an external managed database and object storage before relying on it for important data.

## Security
- The original archive's `.env` was excluded because it contained exposed API credentials. Revoke those credentials and create new ones.
- API keys belong in the hosting provider's secret/environment settings or a local `.env` file only. Never paste them into HTML, GitHub, chat, or screenshots.
- Use HTTPS and a strong unique owner password. The app is a single-owner workspace, not a multi-user collaboration product.
- Back up the `DATA_DIR` folder regularly. The SQLite database contains your projects, chats and attachment metadata; `uploads/` contains uploaded file bytes. The in-app JSON export/restore covers project and chat text, not the original uploaded file bytes.

## Upload limitations
Text is extracted from supported document/text formats and included in the AI prompt when you send your next message. Other file types are stored with the project and can be downloaded again, but their contents are not interpreted or sent as multimodal input in this version. Maximum upload size is 15 MB. Uploading a file does not automatically send it to the AI; after upload, write a message and press Send.

## Migrating an existing original Switchboard chat
When you sign in from the same browser profile that held the original `switchboard.v1` local chat, the upgraded app attempts a one-time import into a new server project. Keep the old browser data until you have confirmed that the imported project appears. Chats stored only in a different browser/device must first be exported from the old app and cannot be auto-discovered by the new server.
